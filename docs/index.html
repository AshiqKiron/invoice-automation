Verification Strategy

🔢 Local Math Check

Recalculates subtotal, per-code tax (math.floor), and total from line items before every API call. Directly prevents AMOUNT_MISMATCH errors.

👤 Human-in-the-Loop

CLI review gate displays full extracted JSON and requires explicit y/n/q confirmation before any write to the accounting system.

🔗 Partner Validation

Fuzzy matches extracted supplier names against API master aliases using difflib. Rejects unmatched partners before API call.

If I Had Another 8 Hours

1. Streamlit Review UI

Side-by-side original image + editable fields. Transforms tool from demo to production-ready. Highest ROI for accountant trust.

2. Confidence Routing

Auto-approve high-confidence extractions; route low-confidence to mandatory review. Reduces human burden at scale.

3. Persistent Retry Queue

SQLite-backed queue for failed invoices with exponential backoff. Prevents data loss during API outages.
