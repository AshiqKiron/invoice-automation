🧾 Invoice Automation Pipeline

AI-powered Japanese invoice intake automation for Sample Trading Co., Ltd.

Architecture

Invoice File → OCR (Tesseract) → LLM (Groq/Llama3) → Structured JSON
     → Partner Matcher → Local Tax Validator → Human Review → Accounting API

Verification Strategy

  • Local Math Check: Recalculates subtotal, tax (floor per code), and total before every API call
  • Human-in-the-Loop: CLI review gate requires explicit confirmation before registration
  • Partner Validation: Fuzzy matching against API master prevents PARTNER_NOT_FOUND errors

Tech Stack

  • OCR: Tesseract (JPN) + PyMuPDF — Free, local
  • LLM: Groq Llama 3 70B — Free tier, <1s latency
  • Validation: Deterministic Python recalculation
  • Cost: ~$0.001/invoice | ~$1/month at 1,000 invoices

How to Run

pip install -r requirements.txt
sudo apt-get install tesseract-ocr tesseract-ocr-jpn
cp .env.example .env  # Add your GROQ_API_KEY
